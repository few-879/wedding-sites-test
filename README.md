# Wedding Invitation Site

Static, multilingual wedding invitation for GitHub Pages.

## Languages

- German is the default language.
- English and Polish are available via the language switcher.
- All content is pre-authored in the HTML; JavaScript only switches visibility.

## Files

- `index.html` - page structure and content blocks
- `styles.css` - layout, typography, and botanical visual styling
- `script.js` - language switching and persistence

## Notes

- The page is designed to be friendly, elegant, minimal, and floral.
- RSVP links currently point to the provided placeholder form URL and can be replaced later.
- To update wording, edit the visible language blocks directly in `index.html`.
